# Screenshots

This directory is the place for real UI captures. Do not commit generated or stand-in images.

| File | What to capture |
| --- | --- |
| `popup.png` | The toolbar popup (`src/popup/popup.html`) on a normal page, with the host, counts, list toggles, and pause button visible. |
| `options.png` | The options page (`src/options/options.html`), including filter-list toggles and the custom block, allow, and paused-site fields. |

After the files are saved here, show them from the Screenshots section of the root README by uncommenting the image lines marked `screenshot: popup` and `screenshot: options`.
